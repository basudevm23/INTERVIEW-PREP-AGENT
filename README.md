The Interview Prep Agent is an AI-powered Streamlit application designed to help users practice interview questions interactively. It integrates Google Gemini for intelligent question generation and feedback, and a TinyLlama LoRA model for scoring candidate responses.

The agent operates in two primary modes:

1. Question Generation Mode (Gemini)

*Users can upload a resume or provide a custom topic.

*Gemini generates a set of interview questions relevant to the provided context.

*Questions are displayed in a numbered list format.

2. Interactive Interview Mode (Gemini + LoRA)

*Gemini dynamically generates questions for the selected topic.

*Users answer each question within the app.

*The LoRA model scores each answer (0–10 scale).

*Gemini provides a model answer and concise feedback for learning and improvement.
